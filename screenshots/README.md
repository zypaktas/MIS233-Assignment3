# Required screenshots

Save the four screenshots captured from the running React app here:

- `all.png`
- `todo.png`
- `in-progress.png`
- `done.png`

Suggested data for all four screenshots: add three tasks; advance one task once (In progress) and another task twice (Done); leave the third task as To do. Then select each filter and capture the full Task Manager card so the filter counts and visible list can be read.

These images must be captured locally after `npm install` and `npm run dev`; this folder intentionally does not contain mock screenshots.
